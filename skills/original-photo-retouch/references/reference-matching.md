# 原片 → Image2 → Photoshop：逐张比较和迭代指南

本轮范围是原已交付的36张独立原片，全部重新生成Image2参考并重新在PS制作。旧版保留。最终统一输出36套PSD/JPEG与原图、第二版Image2、第二版PS三列对比，未完成整轮前不把小样称为最终交付。

## 对上一版的复盘

上一版的失败是把“可执行、没有明显蒙版光晕、保存成功”当成了视觉复刻成功。实际三列对比中，雪山与天空仍灰、颜色分离不足；脸部提亮与环境压光明显弱于参考。局部图层存在并不证明局部塑光有效，低强度再乘不透明度甚至让变化难以察觉。参考提示词同时要求“克制、轻微、保留”等泛化措辞，缺少该照片的主次、光向与具体目标，也没有把禁止扩画面落实到生成后的检查。

因此，旧版的36/36只代表旧标准下的文件交付，不能沿用为本轮完成数。本轮从0/36开始。代码测试、参数拟合、直方图和视觉判断分别记录，不能相互替代。

## 1. 锁定来源与几何

每张绑定原片SHA、已复核的PS解码基线、原尺寸及方向、旧版版本。JPEG按EXIF显示；RAW使用PS相机默认解码，不拿相机嵌入预览替代最终原片。

先决定完整画框还是小幅裁切、是否需按真实水平线校正。裁切至少保留70%面积，所有输出像素都在原画框内；禁止扩画面、补角、生成填充、放大或为贴合参考改变人脸/山脊/建筑透视。几何计划一旦改变，必须重新检查参考可对应性和区域坐标。

## 2. 看原片，写具体的光影诊断

按“主体—环境—关键边缘—保护信息”看整体和100%细节。记录实际主光、遮光、反射、已有明暗面、主体焦点、可用高光与阴影。局部光影依照片需要设计：帽下补脸、维持颊侧/鼻侧/下颌体积、改善雪坡受光与冷谷、压制竞争冰面、整理近水与羽毛层次等。光本来合适的区域写明保留原因，不强凑动作。

每个区域必须写：现在的问题、想达到的结果、光线依据、保护边界。光向来自原片，不能把全脸提平、整圈暗角或整体加对比称为体积塑造。

## 3. 写逐张Image2提示词并真正生成

输入照片是唯一编辑目标。提示词按“画框与结构锁定 → 该张主次 → 局部光影动作 → 色调与层次 → 保护细节”组织。

开头明确：这是同一张照片的后期参考，不是新场景；严禁扩展任何边、虚构画面外信息、移动物体、改变相机位置、换天空或纹理。若允许裁切，给定已决定的裁切范围；不让模型自由扩大画面。禁止文字、水印、边框和拼图。

指定有视觉意义且可用PS实现的局部变化，例如“帽下额头与眼部柔补，让脸成为主焦点；保留右颊及鼻侧较暗面；冰瀑略冷并降低竞争亮度”。不要只写“大师级、漂亮、轻微提亮”。不要要求恢复原片不存在的细节。

使用内置Image2逐张生成，保存实际返回的文件、调用信息、提示词及输入哈希。绝不把脚本调色图冒充Image2。

## 4. 先审参考是否可复刻

并排看原图与生成图：画框四角、主体大小和位置、脸/手/道具、山脊、岸线、建筑、太阳与水纹。确认没有扩画面，没有改变关键身份与结构，没有不可实现的新光源或新纹理。

出现结构偏移时，收紧同一项约束重生成；不能一边接受错误参考一边宣称PS已经相同。高频生成差异不复制，但主要构图、光影与颜色必须仍可对应；如果参考的观感依赖大量重画，该参考退回生成阶段。

## 5. 建立差异清单与采样区域

把原图—参考差异写成表，每行包括区域、原状态、参考目标、PS动作、优先级及保护事项。

| 检查维度 | 具体问题 | 可用动作 |
|---|---|---|
| 全局影调 | 黑点、白点、中间调、灰雾感是否一致 | 原生RGB/明度曲线，避免凭空增强清晰度 |
| 局部明暗 | 脸、雪坡、湖水、衣物或背景是否亮错/暗错 | 经模型标注的独立柔蒙版曲线 |
| 体积 | 受光面与背光面的关系是否接近 | 分开补光、压光，保留鼻侧/颊侧/沟谷 |
| 颜色 | 肤色、天空、湖、暖草、冷影是否偏色 | RGB分通道曲线与颜色/饱和度调整 |
| 主体主次 | 主体与邻近背景的亮度及对比关系是否一致 | 局部填光、压竞争区域，避免硬切边 |
| 几何 | 裁切、水平、主体占比是否一致 | 已审查的小裁切/人工水平线校正 |
| 纹理与边缘 | 原噪声、发丝、羽毛、山脊有无损坏 | 100%检查并减弱或修正蒙版 |

ChatGPT自行识别、标注原图与参考的对应区域。PS的自动主体、天空、物体识别禁用。坐标模块只映射模型标注，统计模块只比较指定区域，不能冒充视觉识别。

先用远离边缘的对应采样点/面判断差异，再检查整片区域与过渡。跨图几何不完全一致时，不能把同一归一化位置强当同一物体；先复核对应关系。

## 6. 用参数拟合辅助初始配方

曲线拟合只输出PS参数，不输出成片像素。对参考与基线进行低频影调/颜色比较，排除生成细节、硬边错位和未对应的区域；先全局，再主体/环境，最后小尺度体积。拟合曲线必须平滑、单调，固定可保护的黑白端点，避免截断纹理。

工作色彩空间必须明确，统计输入与原生PS执行必须同一色彩解释；不能在sRGB量出一条曲线后不经验证直接用于AdobeRGB并宣称精确。参考无ICC时明确使用其显示RGB解释。真实PS导出反馈比模拟图更有权威。

每一张都记录局部塑光是否需要、需要哪些动作、为何无需某动作。局部参数以实际视觉变化和对应区域差异为依据，不复制一组低强度预设。

## 7. 原生PS执行 → 导出工作样 → 对照 → 修正

在原片上建立16位可编辑调整图层与模型蒙版，禁止导入Image2像素。每轮使用新输出版本，记录实际PS执行结果、源哈希与参数。工作样是内部迭代资料，不能自动进入最终36张目录。

对照顺序固定：同画框整体 → 主体/环境区域 → 光向与体积 → 肤色/雪/天空/湖 → 100%焦点和边缘。每次明确最大的剩余差异，再修改对应曲线、强度、颜色或蒙版。一次成功导出不构成完成；已有接近结果仍须做反馈验证和记录。

保持参考目标不漂移：不能把PS成片改成参考、换成更容易的旧参考、故意削弱Image2目标或放宽门槛来凑36张。参考重生成只因原始约束不满足或主要效果不可由原片实现，并记录原因。

## 8. “基本相同”的验收要求

第一层是主要观感：构图与主体占比对应；整体亮暗、主光方向、主体与背景关系、关键色调及受光/背光体积接近，没有一眼可见的灰雾、主体过暗或大色偏。不是要求生成纹理逐像素一样。

第二层是辅助量化：在已复核的对应区域，主体亮度中位差目标不超过Lab L* 3、主要环境不超过4；主次亮度差与参考差不超过L* 4；主要颜色的低频区域中位ΔE00目标不超过5，主体肤色目标更严格。阈值是本项目复刻门槛，不是摄影行业“大师评分”。全图统计可能被相互抵消的小区域欺骗，必须逐关键区域查看。没有可靠对应关系的指标记为无效，不能判通过。

第三层是原片质量：100%主体焦点、肤纹、镜片反射、白帽/白雪、羽毛和发丝保留；不新增黑白剪切、亮暗边、色块、塑料磨皮、虚构锐化纹理或明显噪声恶化。PS原片信息不足的高频限制单独记录，不掩盖主要观感差异。

自动指标通过但视觉明显不近仍退回；视觉看近但局部明显偏差仍复查。轮数不是验收理由。完成记录必须包含最终参考SHA、最终成片SHA、逐区域差异、实际看过的整体和100%细节、剩余可接受的原片限制，以及判断为何已基本接近。

本轮实测的补充规则：雪山r2的天空、暗山体与草地采样已很近，但近景白雪仍偏黄、公路仍偏绿，不能接受。每次整图回看都要增加尚未覆盖的明显差异区域；拟合一个区域的中位色不代表区域全部明暗面或细小物体都近。曲线不能在缺少对应样本的亮度范围内任意外推；白雪/毛帽亮部、冷影和公路应分别验证，必要时拆成局部光色层。

## 暂存空间与内部工作样

内部每轮保留原生PS导出的全尺寸JPEG、配方、真实执行记录和差异表；通过验收的最终轮保存16位可编辑PSD。仅内部工作样可设 `save_psd=false`，最终36张必须实际有完整PSD，不能以配方代替成片。已创建的旧交付、原片和参考不删除。

`scratch_history_policy=discard_owned_history` 只允许在PS原先没有其他文档时执行，每层后确认仍只有本任务文档，清理该任务历史缓存，所有实际调整图层和蒙版保留。存在用户文档就拒绝，不能清除其撤销记录。缓存命令依据 [Adobe Photoshop Scripting Guide](https://community.adobe.com/havfw69955/attachments/havfw69955/photoshop/676396/1/photoshop-scripting-guide-2020-online2pdf-version.pdf)；暂存盘错误须记录真实错误和占用情况，不能删用户文件腾空间。必要时只在零文档、无正在执行作业时正常退出并重新启动PS，使其释放自身临时暂存文件。

## 9. 36张完成后统一交付

本轮计数按36个原片SHA去重。状态顺序：待参考 → 参考待审 → 差异分析 → 标注待审 → PS迭代 → 相似度待审 → 通过。失败、备用、工作样及旧版都不计本轮完成。

统一导出新版本16位PSD、高质量sRGB JPEG、三列对比及图册；原始文件和旧版完整保留。展示注明原图解码来源和所有裁切。36张未全部按新标准完成时，只报告真实进度，不宣称完整交付。

本轮实际反例补充：IMG_4240 旧车身取样矩形混入车窗，旧背光取样混入红路面，拟合会给出与纯车漆相反的明暗动作或错误色偏。先看原像素确认取样属于同一材质、同一受光面；分别取玻璃、亮车漆、暗车漆和轮胎，不能把大矩形默认当作主体。取样区域和执行蒙版用途不同，两者都需视觉复核。把 RGB 参数用于明度混合模式也不能假设等效，须以实际 PS 输出反馈验证。

水平校正后，比较坐标必须同步变化。依据实际原生执行记录的角度、原生尺寸、裁框和中心偏移，仅为核对生成参考的几何对齐展示，并将原取样点按相同几何变换映射到新画框。越界或混入异材质的取样无效，重新人工标记。核对文件同时保留真实生成参考路径/SHA、对齐展示路径/SHA和执行几何；对齐图不得成为 PS 输入或成片，也不得代替真实 Image2 原文件作为最终对比列。IMG_4232 已实际按此方法复核水平校正工作样。

最终保存必须另行核对。不能因为配方相同就声称最终 JPEG 与工作样逐像素相同；本轮 IMG_4310 实际另存有极少 JPEG 舍入差异，已重新看实际最终整幅/原尺寸脸和衣料，重新测最终文件。PSD 必须真正打开读取位深、色彩空间、图层和原始智能对象，再关闭本任务检查文档；QA 记录实际最终 SHA 与独立检查证据。


### 同一灰漆的正面与弯曲反光面

IMG4240实测表明，灰色正面已经接近参考（RGB约114/112/117）并不能证明弯面合格：R5弯面约96/83/100，参考约53/66/90，实际呈紫。R6从R2重做同材质不同光面的加权取样，替换失败层，实际蓝面恢复且保持真实曲率；灰下段仍有残差，所以R6尚不验收。分开取样不等于必须生硬分块上色；若原RGB输入可区分不同光面，优先连续材质蒙版内的单调曲线，仍须真实输出检查渐变、软硬边与全部光面。

DJI0168 R6最终逐像素与工作样一致，9层16位PSD实际打开；纯雪亮面/蓝影、黑路/红路分开核验后验收。真实原JPG远山与道路的光学/处理柔化不以生成细节补回。最终验收只表示主要光向、局部主次和光色基本匹配，不宣称合成细纹复刻或大师认证。
# 拟合覆盖与未取样亮度段（2026-10-15）

对明显混合材质或不同受光面的取样，应先实际查看并拆成纯材质区域，再用 `reference_match.fit_rgb_curves_report(current, reference, sampling_regions, correspondence_reviewed=True, uncovered_identity_weight=.3)`。

该接口均衡各已复核区域的取样数量，返回原/参考SHA、RGB曲线参数、每通道采样亮度范围、节点覆盖与未取样节点；可选正则使未取样亮度段靠近恒等，减少暗部/亮部外推色偏。`fit_rgb_curves` 旧接口默认行为保留。保护强度不是审美阈值，不能借此放宽验收，也不能保证狭窄取样能推断整幅的变化。

返回值只用于生成可编辑PS曲线参数。必须在实际应用蒙版下重新导出PS工作样并看整体/100%边缘；蒙版覆盖强度、材质重绘和空间色差都可能使拟合不能直接命中目标。不能将曲线拟合成功或局部统计通过当作完成。
