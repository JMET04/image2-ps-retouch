# 实际修图后的经验

## 审美与塑光

逐张新参考和材质分区曲线使天空、雪、草、水的光色更稳定。单纯匹配几个Lab指标仍可能让整图偏色；每轮必须重新看整图及原生100%局部。细纹、身份和地形被生成模型重画时，只借用可实现的低频明暗与颜色。

第二版的局部处理仍偏重光色匹配。主动塑光需要先回答：先看哪一处、邻近的受光/转折/背光面如何衔接、哪些区域需要降低竞争、暗面保留什么环境反射。独立塑光图层的数量不能证明效果；同一原生文档的开关输出可以直接检验它们是否真的改变视觉层级。

雪与暗林处在一个宽蒙版时，一起压暗会失去谷底填充。按高光加权的压光可以降低亮雪而保留暗面；它根据明度响应，不是自动识别材质。近乎纯白的雪架还会受固定白端限制，持续增加压光强度反而先压低中间调。可选局部白点控制解决这一具体问题，仍需检查雪边、冷反射和渐变。

蒙版应跟地物的空间尺度，跨雪草的窄条易产生亮带/暗带。模型几何预览只验证覆盖位置，不代表真实羽化或最终效果通过。原图远树的空气透视、景深软化与原生噪声应保留，不能复制生成参考的假细节。

## 保存与恢复

服务容量不足、暂存盘满导致模态窗口、COM尚未注册、保存后拒绝控制、进程缓慢退出，是不同的问题，不能统一归因网络。项目采用有限截止、全局串行、持久未知状态阻塞、成功回执先保存、零文档正常退出及检查点恢复。

超时只代表客户端停止等待，不能证明Photoshop已取消。恢复先核对真实文件和作业状态，不重交已有成功回执的照片。PSD和JPEG保存成功之后还要真正重开PSD核对位深、色彩空间、原智能对象与可编辑调整层；证据绑定当前文件哈希。

认可版本独立存档并逐文件核对，源代码另建Git标签。新一版从0计数，失败、待复核和仅有JPEG的工作样不计完成。每张完成后原子保存来源、实际验证范围和下一步，避免续跑时重读长聊天或重复工作。

## 按需修复与续修

新一轮先复核已有成果，已自然的光影不必再叠加。局部加光应顺着可见受光面，脸部保留鼻梁/颧部的原转折，风景保留冷谷与空气层。曝光响应中的stops描述显示参照曲线强度，不等于真实增加一盏灯或恢复原片动态范围。

圆形灰点在100%原生裁切中确认后，使用同片、同渐变、无结构的相邻小取样。目标和取样及羽化支撑都要检查；小克隆模块不能用于大范围皮肤替换或跨纹理修复。正常色素、毛孔、光学柔化和失焦不应当作脏点删除。

既有PSD续修需要同时绑定原片、执行配方、成功回执和真实重开证明。原生导出修改前样后，在独立工作文档追加可关闭图层，另存新路径。第三版塑光开关和第四版仅修点的前后对比须明确区分；文件复制后可核验字节身份，但不能把新副本路径冒充真正打开过的原路径。

## 第五版：宽水面光场与证据判断

IMG_4528说明了一个独立问题：山坡塑光已有体积，湖面仍缺少参考里中左远水的宽柔亮区。局部塑光不能凭图层存在或区域平均颜色接近就接受。先分别判断大尺度亮暗、蓝青色度、反射与细波，再用宽光场加光、远湖衔接、右侧和近水退让组织水面；不复制生成参考新画的波纹。

单次窄羽化容易出现椭圆灯斑，把岸线保护一起宽羽化又会溢入山岸。`broad_feather_px` 只拓宽一个未羽化的正轮廓，之后扣除独立窄羽化的保护。多次原生羽化得到近似的过渡尺度，不能宣称精确高斯sigma或保证不同PS版本响应完全相同。几何预览通过后仍须实际查看原生蒙版、全幅和湖岸1:1局部。

第五版公开的关层对照只关闭本轮4个 `local_light` 层，轻减青曲线两侧均开启。完整四五版对照另列，避免把关层图误写为全部修改前。最终保存后的JPEG与已接受工作样解码像素一致，文件元数据不同不意味着图像不同；最终PSD另有真实重开证据。

污点：原生100%确认均匀背景上的弥散尘影，同场同传感器位置重复可增强证据。孤立暗团也可能是鸟、云、反射或玻璃影响；证据不足保留。人物痣、毛孔、发丝及真实失焦不按暗点阈值抹去。小克隆只处理已经确认的小范围目标，并检查取样、柔边和重复纹理。

水平：测线工具只能算角度，不能证明现实中的线应水平。开放海平线较可靠，远岸仍受地形和透视影响；山脊、公路消失线、桥面起伏和近岸斜线不能单独证明滚转。IMG_4528缺少独立滚转证据，本轮不再旋转。已经校正的PSD不在续修中反复插值。

本轮36张全幅复审后修改1张、保留35张；35张继承第四版已登记的原生细节，不能声称本轮重新逐像素看过全部照片。36号另看水纹、远近岸、天空、雪鞍和山脊6处原生局部。43项测试只验证编译、参数、兼容性及证据约束；照片的视觉质量来自实际观察，不能由测试数量证明。
