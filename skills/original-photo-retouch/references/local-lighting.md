# 局部光影塑造

近白雪架即使加大压光强度仍抢亮时，先检查固定白端是否为原因。`burn` 可显式设置 `white_ceiling:200..255`（默认255，旧配方不变），以高光权重平滑降低该区域白点；黑端仍为0，回执保存实际端点。它只改变原像素亮度，不能恢复已经丢失的雪纹。需在原生100%核对雪白端、与草地的过渡和原冷反射，不用继续压暗中间调来追纯白亮度。`dodge` 不允许降低白点。

当目标是主动设计光影而非仅匹配调色，先读 [光影设计与关层复核](light-design.md)，明确视觉落点、相邻受光/背光面和环境反射，并用同一原生底稿切换新增塑光层检验贡献。

先查看 PS 原片基线与原像素主体，判断真实主光方向、阴影来源、反光、主体体积和背景视觉干扰。Image2 参考只帮助选择可实现的光影方向。把判断记录在 `lighting_plan`，再标注各个区域；坐标脚本不自动判断光线或审美。

按照片需要选择：帽檐下或逆光面部的柔和补光、眼部阴影的轻微提亮、手和重要道具的视觉权重、沿既有脸颊/鼻侧/衣褶的体积过渡、风光坡面和道路的局部加减光、背景抢亮区域的压光。无需每张凑齐所有动作；已有理想光线的区域保持自然。提亮会放大原有噪声，关键曝光或焦点丢失不能视为可补光。

大尺度塑光用宽软区域，小尺度体积处理查看原像素并用更小强度。补光和压光建独立蒙版与图层，保持原有阴影方向、接触阴影、镜片反射、白衣/白雪层次和发丝过渡。不能全脸提平、描亮边或用环绕硬暗角冒充主体分离。额头、鼻梁、脸颊和下颌按实际受光判断，不按固定人脸模板机械涂抹。

示例数值仅示意，区域来自当前照片实际标注：

```json

  "lighting_plan": {
    "observed_key_light": "冬季日光从左侧照来，帽檐遮住额头与眼部",
    "subject_priority": "先脸部与眼神，再手势，保留环境",
    "shape_intent": "柔和补帽下阴影，右侧轮廓保持体积，减弱背景抢亮",
    "protected_information": ["鼻侧阴影", "眼镜反射", "白衣细节", "发丝"]
  },
  "steps": [
    {
      "kind": "local_light", "name": "帽下补光",
      "action": "dodge", "strength": 25, "opacity": 75,
      "purpose": "补足帽檐阴影中的真实肤质，保留左侧日光",
      "region": {"kind": "annotation", "id": "face_fill"}
    },
    {
      "kind": "local_light", "name": "右侧体积过渡",
      "action": "burn", "strength": 10, "opacity": 30,
      "purpose": "补光后保持既有轮廓的柔和暗面，避免面部变平",
      "region": {"kind": "annotation", "id": "form_shadow"}
    }
  ]
}
```

`strength` 是 0..100 的相对曲线强度，不是物理 EV；再乘独立图层不透明度。编译成平滑单调的 Photoshop 明度曲线，固定黑白端点，不改色相。蒙版羽化保存在标注中，按原尺寸像素执行。只有已复核、绑定原片的 ChatGPT 标注区域可用于 `local_light`；不允许无区域的全图操作冒充局部补光。需要特殊色调或手工曲线时仍可用现有 `curves` 步骤。

同一大尺度区域含亮雪与暗林时，可加 `tonal_focus: "highlights"` 主要压亮面，减少对暗面反射的影响；`shadows` 补光主要作用于暗面，`midtones` 调整中间调，默认 `all` 完全沿用旧曲线。每种曲线都保持黑白端点、控制点单调和动作方向，实际参数写入回执。它按输入明度加权，不能识别雪、皮肤或阴影；蒙版仍须逐张设计。相反方向的操作（高光提亮、暗部压暗）为保持端点斜率而刻意较弱。这些参数不代表物理布光或降噪，最终仍需原生检查白端、暗面与连续过渡。

执行记录保存原光线判断、动作、区域、强度、目的、曲线与标注来源。固定端点不保证所有高光纹理或噪声自动安全：实际成片须适屏和100%检查，再针对每张修改。验收判断主体体积是否改善、受光是否合理、背景主次、肤质/反光是否保留，以及是否出现亮边、暗边或局部贴片。标注和静态曲线测试通过不等于成片完成。
